# Adjusted 3-Day Strength Routines

Updated: 2026-08-28

Use these as the working Lyfta routines for Monday, Wednesday, and Friday. Rest 3 minutes on large compound lifts and 2 minutes on smaller isolation/core work.

## DAY A - PUSH

Goal: keep bench press progress, reduce redundant chest pressing, add consistent shoulder work.

1. Bench Press
   - Warm-up: 20 kg x 20-30, 50 kg x 10-15, 90 kg x 5
   - Work: 130 kg x 5-8, then 2 x 8-10 at 110-120 kg
   - Progression: when 130 kg reaches 8 clean reps, try 132.5-135 kg next top set.

2. Incline Bench Press
   - 3 x 8-12 at 70-75 kg
   - Keep this instead of doing several flat/decline variants in the same session.

3. Lever Seated Shoulder Press
   - 3 x 8-12 at 50 kg
   - Add 2.5-5 kg only when all 3 sets reach 12 controlled reps.

4. Cable One Arm Lateral Raise
   - 3 x 12-20 each side
   - Keep strict form and do not chase load.

5. Cable Standing Fly or Fly
   - 2-3 x 10-15
   - This is accessory work, not another max-effort press.

6. Triceps Pushdown
   - 3 x 10-15 at 75-80 kg
   - Current strength is good; keep the reps controlled.

7. Cable Kneeling Crunch
   - 3 x 10-15

Remove from regular DAY A rotation:
- Decline Bench Press every week
- Close-Grip Bench Press every week
- Extra dip variations after heavy bench and pushdowns

Optional rotation:
- Use Decline Bench Press once every 2-3 weeks instead of Incline Bench Press.
- Use Lever Seated Dip once every 2-3 weeks instead of Triceps Pushdown.

## DAY B - PULL

Goal: keep lat strength, reduce repeated pulldowns, rebuild horizontal row strength, add rear delts.

1. Cable Wide-Grip Lat Pulldown
   - Warm-up: 55 kg x 15-20
   - Work: 77 kg x 8-12 for 3 sets
   - Progression: when all work sets reach 12 reps, move to 80 kg.

2. Cable Seated Row with V Bar
   - 4 x 8-12 at 65-75 kg
   - Priority lift for this day because recent row strength is below the April peak.

3. Lever Seated Row
   - 3 x 8-12 at 63-70 kg
   - Stop 1-2 reps before form breaks.

4. Cable Standing Face Pull with Rope
   - 3 x 12-20
   - Add this every pull day for shoulders, posture, and rear delts.

5. Barbell Curl or Preacher Curl
   - 3 x 8-12
   - Pick one main curl per session.

6. Concentration Curl or Dumbbell Preacher Curl
   - 2 x 10-15
   - Keep this lighter and strict.

7. Captains Chair Straight Leg Raise
   - 3 x 12-20

Remove from regular DAY B rotation:
- Doing Cable Wide-Grip Lat Pulldown, Lever Lateral Wide Pulldown, and Cable Lateral Pulldown with V-Bar all in the same workout
- More than 5 direct biceps sets in one session
- Calves on pull day unless DAY C was missed

Optional rotation:
- Alternate the main pulldown grip weekly: wide grip one week, V-bar the next.

## DAY C - LEGS + CORE

Goal: make legs progressive, keep axial load controlled, add hamstrings, calves, and core.

1. Full Squat
   - Warm-up/mobility: 20 kg x 15-25 for 2 sets
   - If pain-free and technique is stable: add 30-40 kg x 8-12 for 2-3 sets
   - If squat is only mobility work, keep it as warm-up and progress the leg press instead.

2. Sled 45 Degree Leg Wide Press
   - 4 x 8-12
   - Start from current range: 170-180 kg
   - Progression: when 180 kg reaches 12 reps on all work sets, try 190 kg.

3. Lever Lying Leg Curl
   - 3 x 8-12 at 55-60 kg

4. Lever Leg Extension
   - 3 x 10-15
   - Use controlled tempo, especially at the top.

5. Bulgarian Split Squat or Lever Seated Leg Press
   - 3 x 8-12 each side for Bulgarian split squat
   - Or 3 x 10-15 for seated leg press
   - Pick one depending on knee/back comfort.

6. Single Leg Calf Raise Off Step
   - 4 x 10-20 each side

7. Lever Seated Twist
   - 3 x 12-20 each side

8. Plank or Dead Bug
   - 3 sets
   - Plank: 30-60 seconds
   - Dead bug: 8-12 reps each side

Remove from regular DAY C rotation:
- Random arm/chest extras unless a push or pull day was missed
- Shoulder press on leg day unless DAY A shoulder work was skipped

## Weekly Structure

Monday: DAY A - PUSH

Wednesday: DAY B - PULL

Friday: DAY C - LEGS + CORE

If a day is missed, do not skip the routine. Continue with the next routine in order. Example: if Wednesday is missed, Friday becomes DAY B and the next Monday becomes DAY C.

## Progression Rules

1. Keep 1-2 reps in reserve on most work sets.
2. Add weight only after hitting the top of the rep range with clean form.
3. Deload for one week after 4-6 hard weeks, or after any 2-week period where loads regress across several main lifts.
4. Track top-set estimated 1RM for:
   - Bench Press
   - Cable Wide-Grip Lat Pulldown
   - Cable Seated Row with V Bar
   - Sled 45 Degree Leg Wide Press
5. Minimum weekly targets:
   - Chest: 8-12 hard sets
   - Back: 12-16 hard sets
   - Legs: 12-16 hard sets
   - Shoulders: 8-12 hard sets
   - Core: 6-9 hard sets
   - Direct arms: 6-10 hard sets
